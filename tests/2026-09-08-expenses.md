# Pool expense acceptance checks

- Log in as Pool Manager. On Pool, add an expense; confirm the save message no longer refers to Manager Feed and the expense appears under My Pool expenses immediately.
- Edit its date, amount, category, description and paid-by value. Save and reload; verify all changes persist and no duplicate was created.
- Confirm Pool is the only facility choice. Another staff member's pool expenses and other facilities' expenses must not appear or be editable, including through direct API calls.
- An invalid/zero amount must not save. A failed save must leave the form open with an error. Verify keyboard and mobile editing.
- Admin Analytics Expenses must show the Manager Feed layout: total and count tiles; amount/category, date/facility/paid-by, description and Edit on each card. Edit, save, and verify filtered totals refresh.
- Verify date presets, search, empty results and first/last pagination still work. Managers remain denied access to Analytics.
- Verify Club House banner is smaller, straight and centred, with more of the building visible on desktop and mobile.

Automated checks: `node tests/admin-workflows.cjs`, `tests/admin-permissions.sql`, and `tests/pool-expenses.sql`. SQL fixtures are transactional and rolled back. Manual checks remain pending until performed.

This supersedes the September 7 checks that excluded Pool Manager from all expense access: the new scope allows only their own Pool expenses.
